# Student Marks Calculator

## Description
A simple Java console application to calculate a student's total marks, percentage, grade, and result.

## Features
- Enter student details
- Calculate total marks
- Calculate percentage
- Display grade
- Display PASS/FAIL

## Concepts Used
- Java
- Scanner Class
- Variables
- If-Else
- Arithmetic Operator
